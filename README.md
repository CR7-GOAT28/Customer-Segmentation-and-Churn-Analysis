# Customer Segmentation and Churn Analysis

## Project Overview
This project analyzes customer data to identify customer segments, understand customer behavior, and predict potential customer churn risks.

The goal is to help businesses understand their customers and develop strategies to improve customer retention.

## Objectives
- Analyze customer demographics and subscription details.
- Identify different customer segments.
- Understand customer churn patterns.
- Calculate customer risk scores.
- Provide recommendations to improve customer retention.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab
- CSV Dataset

## Dataset Description
The dataset contains 15 customer records and 11 columns.

Key attributes include:
- CustomerID
- Gender
- Age
- TenureMonths
- SubscriptionType
- MonthlyCharges
- TotalCharges
- ContractType
- SupportTickets
- PaymentMethod
- Churn

## Project Workflow
1. Import required Python libraries.
2. Load the customer dataset.
3. Perform data exploration.
4. Check missing values.
5. Analyze customer subscription patterns.
6. Perform customer segmentation.
7. Calculate customer risk scores.
8. Generate recommendations.
9. Validate the results using sample customers.

## Key Analysis
- Customer segmentation
- Subscription type analysis
- Churn analysis
- Customer risk categorization
- Retention recommendations

## Project Files
- `Customer_Segmentation_and_Churn_Analysis.ipynb` – Python analysis notebook.
- `customer_churn_sample(1).csv` – Customer dataset.

## Conclusion
This project demonstrates how Python and data analytics techniques can be used to understand customer behavior, identify churn risks, and generate actionable customer retention recommendations.
